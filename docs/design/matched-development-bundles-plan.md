## Reuse before you write

- [`scripts/stage-source-bundle.sh`](../../scripts/stage-source-bundle.sh): authoritative `SHIPPED_BINARIES` and `GUEST_BINARIES`, native/foreign arch narrowing, `flake.nix`/`flake.lock`, stamp and exact-content checks. Extend this path rather than maintaining a development ship list.
- [`scripts/build-go.sh`](../../scripts/build-go.sh): the one Go build implementation and build stamp; invoke the snapshot copy, not the mutable checkout copy.
- [`internal/flakebundle`](../../internal/flakebundle/flakebundle.go): fresh install generation and atomic active-link swap. Resolve the installed link once to its canonical generation and use only that pinned root for the entire launch.
- [`internal/reporoot.BundledSourceDirFrom`](../../internal/reporoot/reporoot.go): its executable-relative candidates; preserve complete adjacent bundle discovery for system/sealed layouts as well as Homebrew/release and the baked prefix.
- [`StageGuestBinaryCommands`](../../internal/macosuser/runplan.go): its copy/seal/fresh-inode primitive does not make a shared destination immutable for the lifetime of a session. Give each launch a unique child under the existing scoped root and remove only after that session exits.
- The container launch already emits read-only bind arguments in [`jailPrefixMountArgs`](../../internal/cli/run/jailprefix.go). Preserve both helper and flake mounts as read-only.

## Traps

- `YOLO_REPO_ROOT` is not one use: [`reporoot.Resolve`](../../internal/reporoot/reporoot.go) selects a source; `updateRootConflict` in [`update.go`](../../internal/cli/update.go) gates updates; [`preparationenv.go`](../../internal/cli/preparationenv.go) and [`programcaptureproducer.go`](../../internal/cli/programcaptureproducer.go) filter child environments; `check`/launch diagnostics and tests advertise or pin the override. Search all tracked source, tests, scripts, workflows and docs; migrate each by role, then prove no runtime source-selector use remains. Do not leave an alias that silently overrides an adjacent bundle.
- Preserve install-only `SourceDir`/`SourceBranch` semantics. Development classification is a separate explicit build marker consumed before `KindArchive`; test the caller that decides automatic updater checks/notices/prompts, not only the classifier.
- [`BuildJailPrefix`](../../internal/image/prefix.go) is used by the container production callsite; [`BuildGuestPrefix`](../../internal/image/prefix.go) is used by `guestBinariesSeam` in [`commands.go`](../../internal/cli/commands.go). Removing a test or callee alone is not enough: tests must invoke the actual composed production callsite and fail if its builder is wired back in.
- The snapshot input manifest is bounded to the current flake Go fileset and named build/package inputs, including `Justfile`, `scripts/build-go.sh`, `scripts/stage-source-bundle.sh` and `scripts/dev-wrapper.sh`. Include tracked file contents as checked out plus intended non-ignored untracked source inside declared roots; exclude ignored files, `.git`, and external symlink targets. Do not copy every file in an embedded directory or generate a per-file hash inventory. A required excluded symlink is a hard refusal. Freeze all listed inputs first and execute the copied scripts and flake operations with the snapshot as cwd.
- Commit/version stamps are not artifact identity: two dirty builds can share them. Embed one identity over the sorted manifest paths and contents in the launcher and bundle, and use it to validate the pinned canonical installed generation. Do not resolve the mutable active-install symlink separately for helpers and flake consumers.
- A development binary with adjacent bundle can otherwise be detected as `KindArchive`; omitting source stamps is not enough. Add explicit development metadata and suppress automatic updater network checks, disclosure/notices and prompts while preserving explicit update behavior.
- A complete adjacent bundle is supported independent of channel, including system/sealed executable-relative layouts. An incomplete neighboring bundle refuses. Installed-state fallback is authorized only for an explicitly installed launcher identity that matches one pinned active generation; a binary-only distribution/sealed launcher cannot fall through merely because that generation exists.
- The flake's `goSrc` is exactly the `go.mod`, optional `go.sum`, `vendor/`, `cmd/`, `internal/`, and `packs/` fileset in [`flake.nix`](../../flake.nix); that does not mean ignored files or every directory entry belongs in the snapshot. Dirty edits and intended new files in the bounded manifest are included.
- `installPrefix` is a standalone mounted-prefix package, not an image `corePackages` dependency. Removing `guestPrefix` changes `imageIdentity`'s value because it hashes the content of all `flake.nix`; preserve the identity hashing mechanism and image/load/package boundaries, not an invariant hash string.
- macOS Podman CI currently shares `/nix`; it cannot prove the default VM case. A nested jail is likewise blind to the host VM share list. Require a native Mac run using the default machine without `/nix` sharing; do not claim that Linux, Apple Container, or the existing shared-`/nix` nightly covers it.
- `YOLO_REPO_ROOT` is used by CI and the integration harness, so changing resolver precedence alone may make tests green against the old source path. Exercise the production launcher by its path and inspect the reported bundle provenance.

## Don't

- Do not build helpers from Go or Nix during a launch, or silently revive the fallback when a pair is incomplete.
- Do not build the host launcher and helpers from a mutable live tree in separate unsnapshotted steps.
- Do not stage a whole checkout, copy `.git`, ignored files, external symlink targets, or every entry in an embedded directory; do not execute a live-checkout build script after snapshot capture.
- Do not treat equal commit/version strings as sufficient identity for dirty artifacts, or rely on absent source stamps alone to suppress development updater behavior.
- Do not change the Nix image, image loading, `packages:`, runtime default, `PATH`, account home, workspace mounts, credentials, Seatbelt grants, or helper writability. `installPrefix` remains standalone mounted-prefix packaging; the `imageIdentity` content hash may change with `flake.nix`, but its mechanism and image/load boundary do not.
- Do not retain `YOLO_REPO_ROOT` as an alias for launch selection or add another environment selector.
- Do not add automatic generation pruning or an age-based retention rule; completed outputs remain owner-managed until explicit removal.
