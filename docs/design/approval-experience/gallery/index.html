Git: force push to an existing branch

realcapturedpendinggit-push-force

An agent rewrites the history of a branch of example-org/app and force-pushes it. The request shows the old and new ids and nothing that marks the update as non-fast-forward.

A push no grant or working-set entry covers whole files one request for the whole push: internal/gitbroker/approval.go askForPush, which builds the About with pushAbout and the request with pushRequest (approvalauthority.go). FINDING: the request does not say a push is forced. A push is the ref commands the client sent, each '<old> <new> <ref>' (gitproto.Command, gitbroker pushArgv); the broker never checks that <new> descends from <old>, so a force push and a fast-forward are the same request, and the headline and refs read the same.
